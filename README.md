# Laboratorio de Lectura de Mensajes AFTN - ATC-053

[![Ver Demo en Vivo](https://img.shields.io/badge/DEMO-PÁGINA_EN_VIVO-brightgreen?style=for-the-badge&logo=github)](https://squall2103.github.io/laboratorio-atc53/)

Este proyecto es una herramienta interactiva diseñada para facilitar las prácticas de radiotelecomunicaciones en el entorno aeronáutico. Fue desarrollado específicamente para apoyar el curso **ATC-053 Telecomunicaciones**, permitiendo que los estudiantes realicen laboratorios de lectura de mensajes de forma remota y organizada.

## ✈️ Contexto del Proyecto
Debido a la naturaleza online del curso, surgió la necesidad de una plataforma que permitiera a los estudiantes interactuar con mensajes reales del sistema **AFTN (Aeronautical Fixed Telecommunication Network)**. Esta página permitió a la instructora, Milagros Muñoz, asignar ejercicios dinámicos donde los alumnos seleccionan una categoría de mensaje y practican su lectura técnica ante la clase.

## 🛠️ Tecnologías Utilizadas
* **HTML5**: Estructura semántica del laboratorio.
* **CSS3**: Diseño responsivo y profesional utilizando variables y Flexbox/Grid.
* **JavaScript (Vanilla)**: Lógica para la carga dinámica de mensajes y manejo de la interfaz de usuario.

## 📋 Funcionalidades
* **Categorización AFTN**: Organización de 124 mensajes en categorías técnicas (ARR, FPL, CHG, CNL, DEP, DLA).
* **Interfaz Interactiva**: Selección numérica de mensajes para evitar repeticiones durante la clase.
* **Visualización de Mensajes**: Formato tipo terminal para simular la lectura real de sistemas de control de tráfico aéreo.
* **Diseño Responsivo**: Totalmente funcional en dispositivos móviles y computadoras.

## 🚀 Despliegue
